How the code works

  • If the hand size is not divisible by the group size, it returns False immediately.
  • A min-heap of (card value, frequency) pairs always gives the smallest unused value.
  • Each group begins at the current minimum, then takes consecutive values.
  • Extra copies are held aside so one group cannot use the same value twice.

Why holding copies aside works

Within a group, card values must strictly increase by one. A value used in the current group cannot be selected again right away; its remaining copies can only start or extend a later group.

Time: O(N log U) · Space: O(U)

N = number of cards; U = number of distinct values.
